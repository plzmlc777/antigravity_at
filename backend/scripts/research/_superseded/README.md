# 삭제 예정 — 정본(Canon) 커널로 대체된 스크립트

**격리** 2026-08-14 | **삭제 예정** 2026-09-14 (한 달 병행 대조 후)

## 왜 여기 있나

같은 전략의 손익을 계산하는 코드가 연구 스크립트에 **6개** 따로 있었고 그중
**4개**가 숏 수익률 규약을 틀리게 썼다 — `진입/청산 − 1` 은 상한이 없어
90% 폭락한 코인을 숏 치면 +900% 로 기록된다(실제 최대는 +90%).

251 코호트 평균이 **43.41% → 5.15%**, t 가 **5.73 → 1.74** 로 무너졌다.

CANON·PA·REAL 은 커널 한 곳을 지나 서로 어긋나지 않았다. **BT 만 정본 밖에
있어서 BT 만 계속 틀렸다.** 그 예외를 없애는 것이 격리의 목적이다.

대체재: `scripts/research/lifecycle_canon_backtest.py`
  스펙 `build_session_spec`(CANON 세션과 동일) → 조립 `build_pipeline` →
  실행 `GenericBacktester`(커널). 골든 재생이 덮는다.

## 지금 바로 지우지 않는 이유

정본 러너와 **한 달 병행 대조**한다. 오늘 하루에만 결함 셋을 찾았는데 셋 다
테스트가 아니라 **두 결과를 나란히 놓다가** 잡혔다. 대조 상대를 먼저 없애면
다음 결함을 잡을 수단이 사라진다.

교차 검증 실적 (251 코호트, 2026-08-14):

| 변형 | 정본 | 손계산 | 차이 |
|---|---|---|---|
| base | 4.87% | 5.15% | 0.28%p |
| h21 | 5.13% | 5.75% | 0.62%p |
| earlyexit_d7 | 5.76% | 5.93% | 0.17%p |
| earlyexit_d14 | 5.33% | 5.78% | 0.45%p |

남은 차이는 문서화된 둘 — 수수료 8bp(CANON 세션 스펙) 대 10bp, 청산 시가 대
종가. `bearskip` 은 두 구현이 **다른 종목 집합**을 봐서 비교 자체가 성립하지
않는다(아래 참조).

## 격리된 것

| 파일 | 왜 |
|---|---|
| `lifecycle_variant_backtest.py` | 정본 러너가 그대로 대체. 코드 의존 없음(주석 참조뿐) |
| `lifecycle_oos_recheck.py` | 소비자 0. 규약 오염 4번째 구현체였다 |

두 파일 모두 **규약은 이미 고쳐서** 옮겼다 — 격리본이 틀린 채로 남아 있으면
누가 꺼내 썼을 때 같은 일이 반복된다.

## 격리하지 **않은** 것과 이유

| 파일 | 남기는 이유 |
|---|---|
| `lifecycle_three_way_sync.py` | 1군 **4층 비교표** 생성기. `tier1_layer_observation` 적재의 원본이다. 백테스트 스크립트가 아니다 |
| `notional_cap_portfolio_sim.py` | 규약 처음부터 정상. **실거래 사이징 20% 의 근거**이고 드라이버 주석이 가리킨다 |
| `lifecycle_variant_sizing_v2.py` | 규약 정상. 포트폴리오 복리 시뮬 — 정본 러너는 **거래 단위**라 대체 못 한다 |
| `lifecycle_leverage_sim.py` | 위와 같음. `notional_cap_portfolio_sim.resolve_trade` 재사용 |
| `lifecycle_variant_x_sizing_sim.py` | 규약 결함이 있었으나 수정됨. 포트폴리오 시뮬이라 미대체 |

**아직 남은 정본 밖 경로가 하나 있다** — `lifecycle_three_way_sync.bt_trade`.
4층 비교표의 BT 열을 자체 구현으로 계산한다. 정본 러너를 호출하도록 바꾸면
BT↔CANON 격차가 구조적으로 0 이 되지만, 표의 숫자가 바뀌므로(진입 시가/종가,
수수료) 별도로 검증하고 진행해야 한다.

## bearskip 주의

`lifecycle_variant_backtest.json` 의 `bearskip` 행은 **필터가 거의 안 걸린
base 복사본**으로 봐야 한다. BTC 사전 수익률을 로컬 DB 1분봉 32일로 재서
251건 중 **9건**만 BEAR 로 걸렀다(짝지은 차이 +0.00%p, t nan).

정본 러너는 스포너와 같은 `compute_btc_30d_pre_ret`(바이낸스 일봉 API, 상장
전일 종가 기준 30일)을 써서 **62건**을 걸러낸다 — CANON 세션을 실제로 만드는
그 함수다. n 189 / 평균 8.28% / t 2.49.
