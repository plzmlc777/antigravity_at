## 🚫 초판이 왜 틀렸나 — 반드시 읽어라

초판의 `z_vel ≤ -1.0` 은 **상한이 없었다**. 집단 통계에서 "z_vel 이 낮을수록
좋다"가 맞았으므로 그대로 옮겼는데, **슬롯이 매번 유니버스 최저값을 고른다**는
걸 계산에 안 넣었다. 그 자리는 z_vel −1.5 아래이고, 촘촘한 구간 실측에서

    -2 ~ -1.75 구간   1.96일에 **95건**    z +0.89 (위약 못 넘음)
    -2 아래           **한 칸도 없음**     최소 표본 50건 미달

즉 **재본 적 없는 영역**을 진입 규칙으로 박았다. 실현 결과:

    슬롯 1 · 보유 120분   구_하한만 **-18.8%**   밴드 +5.6%

교훈: **집단 통계 조건을 그대로 진입 규칙으로 쓰지 마라.** 슬롯이 부분집합을
어떻게 고르는지까지 정해야 조건이 완성된다.

## 1. 신호 정의 (초판과 동일 — 바뀐 것 없음)

틱 → 1분봉 종가. 체결 없는 분은 앞 값으로 채운다.

```
지평 h = 60분 · 창 W = 360분 · 간격 D = 180분

승패    win[j] = 1 if (close[j+h]/close[j] - 1) > 0
승률    rate(t) = mean( win[ t-h-W : t-h ] )      ← shift(h). 승부가 끝난 것만
속도    vel(t) = rate(t) - rate(t-D)
가속    acc(t) = vel(t) - vel(t-D)

N_eff = W/h = 6        겹치는 창이라 독립 관측이 6개뿐. W 로 두면 z 가 7.7배 부풀려진다
se    = sqrt( p(1-p)/N_eff ),  p = clip(rate, 0.01, 0.99)
z_vel = vel / (se * sqrt(2))
z_acc = acc / (se * 2)
```

## 2. 생존 조건

```
직전 60분 분당 체결 수 중앙 >= 5
```

거래가 없어 멈춰 있던 종목이 깨어난 것을 신호로 읽지 않는다.

## 3. 진입 규칙 **(개정)**

```
밴드    -1.25 <= z_vel <= -0.25          ← 상한이 핵심. 꼬리 밖으로 못 나간다
배제    z_acc >= +0.5                     급등 신호 회피
방향    롱만
슬롯    10                                자본은 슬롯 수로 나눈다
선별    빈 슬롯을 z_vel **낮은 순**으로 채움 · 같은 종목 중복 금지
보유    120분 · 익절·손절 없음 (검정한 형태 그대로)
앵커    벽시계 5분 격자 (:00 :05 ... :55)
유니버스 configs/rsi_live_universe.txt
```

⚠ 앵커는 **벽시계 격자**에 맞춘다. 종목마다 첫 봉 시각이 달라 그냥 5칸씩 건너뛰면
  격자가 어긋나고, 그러면 어떤 시각엔 후보가 한 종목뿐이라 "최저 선별"이 무의미해진다.

⚠ 숏은 넣지 않는다. z_vel >= +1 구간이 대칭으로 나쁘지만 숏 위약 자체가
  음수(-0.245% @120분)라 손익 구조가 다르다. 롱만 먼저 확인한다.

## 4. 동결 시점 실측 (1.96일 · 359종목)

집단 통계 — 최대통계량 위약 1000회, 42칸 재탐색, 하나빼기 표준화:
관측 |z| **8.88** vs 위약 중앙 2.12 / 95분위 3.16 / 최대 4.43. **p 0.000 · 26/42칸**.

슬롯 실현 (복리, 마찰 0.036% 반영):

| 설정 | 밴드_최저 | 밴드_무작위 5~95분위 | 항상롱 |
|---|---|---|---|
| 슬롯 1 · 120분 | +5.60% (18거래) | -7.71 ~ +14.30 | +2.16% |
| **슬롯 10 · 120분** | **+5.69%** (180거래) | **+0.48 ~ +5.47** | +0.62% |
| 슬롯 20 · 120분 | +3.90% (360거래) | +1.03 ~ +4.71 | +0.06% |
| 슬롯 10 · 30분 | +2.10% (730거래) | -3.23 ~ +3.94 | -2.04% |

**슬롯 10 · 120분이 유일하게 무작위 95분위를 넘었다**(+5.69 > +5.47).

선별 방향(`최저 > 중앙 > 최고`)이 6개 조합 중 **5개**에서 유지된다.
예외는 슬롯1·30분(73거래)뿐이다.

## 5. 이 결과가 답하지 **못하는** 것

1. **표본이 1.96일이다.** +5.69%를 연율로 읽으면 안 된다. 방향만 섰고 크기는 못 믿는다.
2. **회전 위약은 기간 내부만 답한다.** 다른 장에서도 되는지는 모른다.
3. **겹침.** 슬롯 10 · 120분이면 동시에 10포지션이라 관측이 독립이 아니다.
4. **같은 되돌림일 것이다.** 승률이 떨어졌다 = 가격이 떨어졌다. 새 축이 아니라
   같은 축을 덜 더럽게 잰 것으로 본다.
