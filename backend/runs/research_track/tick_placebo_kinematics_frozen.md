## 1. 신호 정의

틱 → 1분봉 종가로 시작한다. 체결 없는 분은 앞 값으로 채운다.

```
지평   h = 60분      승패를 정의하는 앞으로 보는 시간
창     W = 360분     승률을 재는 창
간격   D = 180분     속도·가속을 재는 뒤돌아보기
```

**승패** — 앵커 j 에서 앞으로 h 분 수익률이 양수면 승.

**승률** (⚠ 미래참조 차단의 핵심)

```
rate(t) = mean( win[ t-h-W : t-h ] )        ← shift(h). 승부가 끝난 것만 쓴다
```

앵커 j 의 승패는 j+h 에 확정된다. 시각 t 에서 쓸 수 있는 건 j ≤ t−h 뿐이다.
이 후퇴를 빼먹으면 승률이 미래를 안다.

**속도·가속**

```
vel(t) = rate(t) − rate(t−D)
acc(t) = vel(t) − vel(t−D)
```

**표준화** (⚠ 유효표본을 낮추는 게 핵심)

```
N_eff = W / h = 6           승패 계열은 겹치는 창이라 독립 관측이 6개뿐
se    = √( p(1−p) / N_eff ),  p = clip(rate, 0.01, 0.99)
z_vel = vel / (se · √2)
z_acc = acc / (se · 2)
```

`N_eff` 를 W(=360)로 두면 z 가 **7.7배** 부풀려진다.

## 5. 이 결과가 답하지 **못하는** 것

1. **표본이 1.83일이다.** 회전 위약은 "이 기간 안에서 구간 배정이 정보를
   갖는가"만 답한다. 다른 기간은 모른다.
2. **겹침이 극심하다.** 120분 보유에 5분 앵커면 이웃끼리 115분 겹친다.
   n 59,265 는 독립 관측이 아니다.
3. **실행을 안 쟀다.** 하락가속만 하루 3만 건인데 슬롯 1 이면 그중 하나를
   골라야 한다. 고르는 방법이 결과를 바꾼다.
4. **같은 되돌림일 것이다.** 승률이 떨어졌다 = 가격이 떨어졌다. 새 축이
   아니라 같은 축을 덜 더럽게 잰 것으로 본다. 가격 기반 되돌림이 1.7~3.4bp
   로 마찰에 먹혔는데 이건 자릿수가 다른 이유가 잡음 제거라면, 그 차이가
   다른 기간에도 유지되는지가 관건이다.
