# Skill Smoke Test Convention

**작성일**: 2026-04-08
**상태**: P0 표준 — skill-architect가 생성하는 모든 스킬에 의무 적용
**관련 문서**: [skill_architect_design.md](skill_architect_design.md)

---

## 1. 목적

`skill-architect`가 AI 생성 스킬의 품질을 **사용자 판단 없이** 검증하려면, 모든 스킬이 **동일한 인터페이스로 자기 검증(self-test) 출력을 낼 수 있어야** 한다. 이 문서는 그 인터페이스 계약을 정의한다.

검증 체인에서 이 컨벤션이 차지하는 위치:
1. **Smoke run** (← 이 컨벤션) — 문법/import/고정 입출력 재현성
2. Paper backtest — 실제 데이터 기반 성과
3. KPI gate — 12% 월 복리 기준
4. Reproducibility — smoke run 재실행 바이트 동일 확인 (#1에 의존)

## 2. 의무 규칙

### 2.1 CLI 플래그

모든 스킬 스크립트 (`.claude/skills/<family>/scripts/*.py`)는 다음 플래그를 구현한다:

```bash
python3 <script>.py --self-test
```

### 2.2 출력 형식

- **stdout**: 유효한 단일 JSON object만 출력. 다른 문자열 (print, logging) 금지
- **exit code**: 0 = pass, 1 = fail
- **stderr**: 자유 (디버그용). skill-architect는 무시함

### 2.3 JSON 스키마

```json
{
  "skill": "<module_name>",
  "version": "<SKILL.md frontmatter version>",
  "self_test": "pass | fail",
  "fixture_hash": "<SHA256 of fixed input, hex>",
  "output_hash": "<SHA256 of output, hex>",
  "outputs": { "...": "...any structured data..." },
  "duration_ms": 12,
  "error": null
}
```

| 필드 | 필수 | 설명 |
|---|---|---|
| `skill` | ✅ | 스킬 이름 (family/script 또는 SKILL.md의 name) |
| `version` | ✅ | SKILL.md frontmatter의 version 문자열 |
| `self_test` | ✅ | `"pass"` 또는 `"fail"` |
| `fixture_hash` | ✅ | 고정 입력의 SHA256. 동일 스크립트는 항상 동일 해시여야 함 |
| `output_hash` | ✅ | 출력 `outputs` 필드를 canonical JSON으로 직렬화 후 SHA256 |
| `outputs` | ✅ | 스킬의 실제 출력 데이터 (재현성 검증용) |
| `duration_ms` | ✅ | 실행 소요 시간 (대략) |
| `error` | fail 시 | 실패 사유 (`None` 또는 에러 메시지) |

### 2.4 결정성 요구사항

Self-test 실행은 다음 조건 하에 **반복 실행 시 `output_hash`가 바이트 동일**해야 한다:

- 같은 Python 버전
- 같은 backend/app/core 커밋
- 외부 네트워크/DB 접근 없음
- 시간 의존 로직은 고정 타임스탬프 사용 (`datetime(2026, 1, 1, 0, 0, 0)` 같은)
- 랜덤성은 고정 seed (`random.seed(42)`, `np.random.seed(42)`)

이 요구는 skill-architect의 검증 체인 4단계 (reproducibility check)의 기반이다.

## 3. Boilerplate 템플릿

skill-architect가 새 스킬 생성 시 삽입하는 기본 골격:

```python
# AUTO-GENERATED by skill-architect (signal: GAP-YYYYMMDD-NNN)
# Created: <ISO-8601 timestamp>
# DO NOT EDIT MANUALLY — re-run skill-architect to regenerate
"""<Skill purpose — one line.>"""
from __future__ import annotations

import argparse
import hashlib
import json
import sys
import time
from pathlib import Path
from typing import Any, Dict

# ─── Bootstrap: backend on sys.path for app.core.* imports ───────────────
_SCRIPT_DIR = Path(__file__).parent
_BACKEND_DIR = _SCRIPT_DIR.parent.parent.parent.parent / "backend"
if str(_BACKEND_DIR) not in sys.path:
    sys.path.insert(0, str(_BACKEND_DIR))

# Trust-anchor imports: backend/app/core/*.py only.
# Do NOT import from other AI-generated skills (recursive trust forbidden).
from app.core.<module> import <function>  # noqa: E402

SKILL_NAME = "<family>/<script>"
SKILL_VERSION = "0.1.0"

# Fixed fixture for self-test — never varies.
_SELF_TEST_FIXTURE = {
    "key": "value",
    # ... deterministic input ...
}


def run(params: Dict[str, Any]) -> Dict[str, Any]:
    """Pure logic entry point. Takes params dict, returns output dict."""
    # ... orchestrate backend/app/core/* calls ...
    return {"result": ...}


def _canonical_json(obj: Any) -> str:
    return json.dumps(obj, sort_keys=True, separators=(",", ":"), ensure_ascii=False)


def _sha256(text: str) -> str:
    return hashlib.sha256(text.encode("utf-8")).hexdigest()


def self_test() -> Dict[str, Any]:
    t0 = time.time()
    try:
        outputs = run(_SELF_TEST_FIXTURE)
        status = "pass"
        error = None
    except Exception as e:  # noqa: BLE001
        outputs = {}
        status = "fail"
        error = f"{type(e).__name__}: {e}"
    duration_ms = int((time.time() - t0) * 1000)
    return {
        "skill": SKILL_NAME,
        "version": SKILL_VERSION,
        "self_test": status,
        "fixture_hash": _sha256(_canonical_json(_SELF_TEST_FIXTURE)),
        "output_hash": _sha256(_canonical_json(outputs)),
        "outputs": outputs,
        "duration_ms": duration_ms,
        "error": error,
    }


def main() -> int:
    parser = argparse.ArgumentParser()
    parser.add_argument("--self-test", action="store_true",
                        help="Run self-test and emit JSON report to stdout")
    # ... other flags ...
    args = parser.parse_args()

    if args.self_test:
        report = self_test()
        print(_canonical_json(report))
        return 0 if report["self_test"] == "pass" else 1

    # ... normal CLI path ...
    return 0


if __name__ == "__main__":
    sys.exit(main())
```

## 4. 기존 스킬에 대한 backport 정책

- **의무 대상**: skill-architect가 **새로 생성하는 모든 스킬** (2026-04-08 이후)
- **선택 대상**: 기존 손으로 작성된 at-* 스킬은 backport가 권장되지만 강제 아님. 운영 세션 무중단 원칙에 따라 점진적 적용
- **검증 파이프라인**: skill-architect의 validation step은 오직 `--self-test` 플래그를 가진 스킬에만 적용됨. 미구현 스킬은 validation 건너뛰고 `self_test: "not_applicable"`로 기록

## 5. 실패 모드

| 조건 | skill-architect 처리 |
|---|---|
| `--self-test` 플래그 미구현 | 생성 거부 (boilerplate 누락 → syntax_error) |
| stdout에 JSON 외 출력 | 생성 거부 (파서 실패) |
| `self_test: "fail"` | status `rejected_post_validation` |
| `output_hash`가 2회 실행 간 불일치 | status `rejected_non_deterministic` |
| 실행 시간 > 60초 | status `rejected_timeout` (경량 smoke test 원칙) |

## 6. 검증 예시

```bash
# 정상 케이스
$ python3 .claude/skills/at-monitor/scripts/regime_detector.py --self-test
{"skill":"at-monitor/regime_detector","version":"0.1.0","self_test":"pass","fixture_hash":"abc123...","output_hash":"def456...","outputs":{"regime":"trending_up","score":0.73},"duration_ms":12,"error":null}
$ echo $?
0

# 반복 실행 시 output_hash 동일 확인
$ python3 <script> --self-test | jq -r .output_hash
def456...
$ python3 <script> --self-test | jq -r .output_hash
def456...  # ← 바이트 동일
```

## 7. 향후 확장

- **복수 fixture 지원**: 단일 fixture로 불충분한 경우 `_SELF_TEST_FIXTURES` 리스트로 확장, 각 fixture별 pass/fail 보고
- **Golden master 파일**: `outputs`를 디스크의 `self_test_golden.json`과 diff하여 회귀 탐지 (Phase B 이후)
- **Benchmark 연동**: `duration_ms`를 시계열로 누적하여 성능 회귀 경고 (P2)

이 확장들은 P0 단계에서 구현하지 않는다 — skill-architect가 첫 번째 스킬을 생성한 후에 실제 필요를 보고 결정.
